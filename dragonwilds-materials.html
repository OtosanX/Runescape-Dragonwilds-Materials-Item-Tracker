About this list & saving your changes

This covers confirmed material families and their uses, not literally every one of the game's 1000+ individual items. Entries tagged NEW were added with today's 1.0 launch — some exact recipes are still being confirmed by the community as the patch is only hours old. For anything not listed here, check dragonwilds.runescape.wiki.

Your edits auto-save in this browser. Save updated file embeds your current list into a standalone HTML file you can keep, back up, or send to someone else. JSON export/import is useful for moving just the data — when importing and merging, any name matches (ignoring case, spacing, and punctuation) will prompt you to keep the existing entry, use the imported one, or edit a combined version before applying.

The Changelog window has its own export and merge. Export as JSON to hand your history to someone else, or as Markdown for readable patch notes. Merge a changelog folds another person's JSON export into yours: entries are matched on timestamp, editor, and content, so re-merging the same file adds nothing and two people working from the same copy end up with one combined history. Merging only touches the log — your material list is untouched.
